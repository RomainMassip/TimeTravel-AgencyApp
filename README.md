# TimeTravel-AgencyApp by Romain MASSIP
Interactive web application for a fictional luxury time travel agency.

## 🛠️ Technologies
* Next.js 16 + React
* Tailwind CSS
* Groq API (llama-3.3-70b-versatile)
* Vercel

## ✨ Features
* Landing page interactive with hero section
* 3 time travel destinations (Paris 1889, Crétacé -65M, Florence 1504)
* AI chatbot assistant (Chronos)
* Responsive design

## 🚀 Installation
```bash
git clone https://github.com/votre-repo/TimeTravel-AgencyApp
cd timetravel-agency
npm install
```

Créez un fichier `.env.local` :
```
GROQ_API_KEY=your_api_key_here
```

```bash
npm run dev
```

## 🤖 AI Tools Used
* v0.dev — UI generation
* ChatGPT — assistance
* Groq API — chatbot (llama-3.3-70b)

## Deployment

Hosted on Vercel.
